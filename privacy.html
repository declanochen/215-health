Privacy Policy

215 Log Health · Last updated November 10, 2026

Who this app is for

215 Log Health is a personal app used by one person, its owner, to view their own health and fitness data. It is not offered to the public.

What data it accesses

With the owner's permission through Google sign-in, the app reads data from the Google Health API in read-only mode. This can include sleep, heart rate, heart rate variability, resting heart rate, steps, activity and exercise sessions, calories, and weight.

How the data is used

  • Data is used only to show the owner's own health trends alongside their personal workout log.
  • Data is not sold, shared with third parties, or used for advertising.
  • Data is not used to train machine learning models.
  • The app only reads data. It does not write to or change the owner's Google Health or Fitbit account.

Where the data is stored

Sign-in tokens are stored only on the owner's own computer, with file permissions that restrict access to the owner. Summarized daily figures are stored in the owner's private workout dashboard, which only the owner can access.

Revoking access

Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
